# Lume Design — Photography & Visual Studio

A modern, responsive, editorial photography studio website built with pure HTML5, semantic CSS3, and vanilla JavaScript. Designed for zero-dependency static deployment to GitHub Pages.

---

## Overview

**Lume Design** features a clean editorial aesthetic suited for fine art portraiture, architectural spatial documentation, and commercial campaigns. 

### Key Features
- **Editorial Typography & Layout:** Styled using *Cormorant Garamond* and *Plus Jakarta Sans* on an open, warm-neutral grid.
- **Dynamic Portfolio Filter:** Client-side category switching (All, Editorial, Portrait, Architecture, Commercial).
- **Interactive Lightbox Modal:** Fullscreen photo preview with keyboard navigation (`Esc`, `ArrowLeft`, `ArrowRight`), metadata captions, and index counter (`01 / 06`).
- **Commission Packages:** Clear service breakdowns with one-click package pre-selection into the inquiry modal.
- **Responsive Navigation:** Clean desktop layout collapsing into a slide-down mobile menu.
- **Pure Static Delivery:** Zero dependencies, build tools, or bundlers required.
